\section{Reproduction and revision note}

\subsection{Code and data}

The supplement contains the current Cartan and projection formulas, an exterior-algebra calculation, exact symbolic results, and the data for the three figures. It requires Python 3.11 or later and the dependencies in \texttt{script/requirements.txt}; the notebook additionally requires a Jupyter environment. Recomputing the results and rendering the saved results are separate operations. From the \texttt{script} directory:

\begin{lstlisting}
python -m pip install -r requirements.txt
python -B paper03ec.py verify
python -B paper03ec.py recompute --output ../recomputed
python -B paper03ec.py render --data ../data/paper03ec_v4 --output ../rendered
\end{lstlisting}

Output directories must be new. The notebook \texttt{DPPUv2\_Paper\_Figures\_EC.ipynb} loads saved data by default through its adjacent viewer; recalculation is an explicit option that writes to a new time-stamped folder. The manifest records the prescribed profiles, coordinate chart, conventions, and file hashes. The symbolic calculation reproduces the tensor identities, scalar reductions, static transverse formulas, and Euler equations, the stationary-branch coefficients, the coupled-profile frequency terms, and the Nil harmonic-lattice formulas. Figure rendering uses the saved numerical data independently of that calculation.

\subsection{Revision note}

Version 4 adopts the complete-NY curvature coefficient $1/2$ and the global normalization of Papers I--II. Earlier computational inputs used $T_{\rm geom}=-\tau$; the present supplement uses geometric torsion directly. The curvature comparison distinguishes irreducible EC-Weyl from Ricci-tracefree EC curvature and extends Paper II's static identities to the variations specified here.

The preceding universal Palatini-protection and unchanged spin-2 kinetic claims, the full homogeneous Nil minimum and its $|\kappa^2\theta|=1$ threshold, and the particle-mass and spin-1 tachyon interpretations are withdrawn. Sections 3--5 give the restricted equations and deformation coefficients in their place. The internal-dual Pontryagin interpretation and the associated topological and chiral conclusions are also withdrawn. Appendix C gives the coordinate and path comparisons; the repository's \texttt{CHANGELOG.md} records the detailed changes to the preceding version, including interaction order and normalization.
